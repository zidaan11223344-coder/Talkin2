# إصلاح دخول/خروج الغرف وحفظ الأعضاء

- `خروج اسم_الغرفة` يزيل الغرفة من الغرف المتصلة والمحفوظه.
- `دخول اسم_الغرفة` يعيد الدخول حتى لو كان اسم الغرفة موجوداً سابقاً في `tracked_rooms.json`، طالما أنها ليست متصلة حالياً.
- عند دخول الغرفة، يتم جلب أعضاء الغرفة من قاعدة البيانات على دفعات وحفظهم في `room_users.json`، مع fallback إلى occupants_list عبر WebSocket إذا تعذر جلبهم من قاعدة البيانات.
- جلب أعضاء قاعدة البيانات أصبح paginated حتى لا يتوقف عند حد 1000 عضو.
- أمر `اعضاء` يعرض العدد فقط ولا يرسل أسماء الأعضاء داخل WebSocket.
- لا يتم حذف سجل الأعضاء المحفوظين عند الخروج من الغرفة.


## إصلاح تشغيل المنصات ذات نظام الملفات للقراءة فقط
- يختار `bot.py` مجلد بيانات قابلًا للكتابة تلقائيًا، ويفضّل `/data` أو `/var/data` أو مجلد المنزل، ثم `/tmp/talkin-data` كحل أخير.
- إذا كانت المنصة تدعم قرصًا دائمًا، اربطه على `/data` أو عيّن المتغير `BOT_DATA_DIR` إلى مسار القرص. مجلد `/tmp` قد يُمسح عند إعادة التشغيل أو النشر.
- أوامر التنقيب تعمل فورًا باسم المستخدم ولا تنتظر طلب قائمة الأعضاء؛ مفتاح الاسم يبقى ثابتًا لتفادي فصل المخزون عند تعرّف البوت على ID لاحقًا.
- أمر `ايدي` يستمر في طلب ID الأصلي من الخادم عند عدم وجوده محفوظًا، وتُحفظ هويات الأعضاء في `room_users.json` ضمن مجلد البيانات المحدد.
