# إصلاح دخول/خروج الغرف وحفظ الأعضاء

- `خروج اسم_الغرفة` يزيل الغرفة من الغرف المتصلة والمحفوظه.
- `دخول اسم_الغرفة` يعيد الدخول حتى لو كان اسم الغرفة موجوداً سابقاً في `tracked_rooms.json`، طالما أنها ليست متصلة حالياً.
- عند دخول الغرفة، يتم جلب أعضاء الغرفة من قاعدة البيانات على دفعات وحفظهم في `room_users.json`، مع fallback إلى occupants_list عبر WebSocket إذا تعذر جلبهم من قاعدة البيانات.
- جلب أعضاء قاعدة البيانات أصبح paginated حتى لا يتوقف عند حد 1000 عضو.
- أمر `اعضاء` يعرض العدد فقط ولا يرسل أسماء الأعضاء داخل WebSocket.
- لا يتم حذف سجل الأعضاء المحفوظين عند الخروج من الغرفة.
